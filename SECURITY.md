# Security policy

Report a vulnerability in the Edka CLI privately, through
[Report a vulnerability](https://github.com/edkadigital/cli/security/advisories/new)
on this repository. Leave it out of public issues and pull requests.

Include the CLI version (`edka version`), your operating system, and the steps that
show the problem. Leave out live credentials: tokens, kubeconfigs and secret values.

Fixes ship in the latest release. `edka upgrade` installs it.

[docs/security.md](docs/security.md) describes how the CLI handles credentials,
tokens and confirmations.
